# apdo-studio-web

APDO STUDIO의 **공개 정적 페이지**입니다. 앱 소스 코드는 여기에 없습니다.

| 경로 | 내용 |
|---|---|
| `/` | 스튜디오 소개 |
| `/privacy/puzzle-01.html` | 정리 퍼즐 개인정보처리방침 |
| `/terms/puzzle-01.html` | 정리 퍼즐 이용약관 |
| `/play/puzzle-01/` | 정리 퍼즐 **시험판** (웹) |

> 개인정보처리방침 URL은 App Store·Google Play 제출의 **필수 요건**입니다.
> 그래서 이 페이지들은 앱 서버가 아니라 GitHub Pages에 둡니다 — 서버가 죽어도 살아있게.
